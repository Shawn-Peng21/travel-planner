# Travel Planner 🌍

## 📌 Overview

Travel Planner is a web-based application designed to help users plan trips efficiently by integrating maps, route optimization, and attraction recommendations.

The project is still under development, and the current focus is on building a modular system that combines:
- Map visualization
- Route planning
- Travel itinerary generation

---

## 🚧 Current Status

This project is **actively under development**.

### ✅ Completed so far:
- Basic HTML/CSS/JavaScript project structure
- Integrated AMap (Gaode Map) API key setup
- Basic map rendering on webpage
- Simple UI layout for travel planning interface

### 🔄 In progress:
- Route planning between multiple locations
- User input system for destinations
- Itinerary generation logic
- UI improvement and responsive design

### ⏳ Planned features:
- Smart route optimization (shortest time / shortest distance)
- Travel recommendation system (POIs)
- Export itinerary as PDF
- Save user travel plans (local storage / backend)
- Optional login system

---

## 🧠 Technical Stack

- Frontend: HTML, CSS, JavaScript
- Map API: AMap (Gaode Map API)
- Future Backend: (TBD - possibly Node.js or Java Spring Boot)
- Data Handling: JSON-based travel data structure (planned)

---

## 🗺️ Project Idea

The goal is to simulate a real-world travel planning system:

User selects multiple destinations → system calculates optimal route → generates itinerary → displays on map.

This project is inspired by real-world applications such as Google Maps and Trip planning tools.
